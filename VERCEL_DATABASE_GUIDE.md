# Vercel Deployment & Database Integration Guide
## For Nurul Arefin Nabil Portfolio & Tuition Portal

This document explains how to handle database storage and tuition applications when hosting on Vercel.

---

## 1. Recommended Database Options for Vercel

Vercel is a serverless frontend/API platform. The best database options to pair with Vercel are:

### Option 1: Supabase (PostgreSQL) — ⭐ Recommended
- **Why**: 100% Free tier, serverless PostgreSQL, built-in REST API, instant JavaScript client SDK (`@supabase/supabase-js`).
- **Dashboard**: Features an Excel-like dashboard where you can view, filter, edit, and export all tuition applications.

### Option 2: Firebase Firestore (NoSQL)
- **Why**: Real-time cloud database by Google, zero setup required for JS SDK, free generous quota.

### Option 3: MongoDB Atlas Cloud
- **Why**: Great if you prefer JSON document database structure.

### Approach B: Storing in Supabase Database (Automated Record Keeping)

#### Step 1: Create Table in Supabase
Run this SQL query in your Supabase SQL Editor:

```sql
CREATE TABLE tuition_applications (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL,
    student_name TEXT NOT NULL,
    guardian_phone TEXT NOT NULL,
    student_class TEXT NOT NULL,
    medium TEXT NOT NULL,
    subjects TEXT NOT NULL,
    location TEXT,
    mode TEXT,
    schedule TEXT,
    notes TEXT,
    status TEXT DEFAULT 'Pending'
);
```

#### Step 2: Add Supabase SDK to `index.html`
Add this script tag in your `index.html`:
```html
<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
```

#### Step 3: Connect in `app.js`
Replace your Supabase credentials in `app.js`:
```javascript
const SUPABASE_URL = 'https://YOUR_PROJECT_REF.supabase.co';
const SUPABASE_KEY = 'YOUR_ANON_PUBLIC_KEY';
const supabase = window.supabase.createClient(SUPABASE_URL, SUPABASE_KEY);

// Inside Form Submit Handler:
const { data, error } = await supabase
    .from('tuition_applications')
    .insert([ applicationData ]);

if (error) {
    console.error('Database Error:', error);
} else {
    console.log('Successfully saved to Supabase!');
}
```

## 3. How to Deploy to Vercel

1. Push your project to GitHub:
   ```bash
   git add .
   git commit -m "Add portfolio and tuition system"
   git push origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository `portfolio`.
4. Vercel will automatically detect `index.html` and deploy it instantly under your free `.vercel.app` domain or custom domain (e.g. `arefin.binarybardbd.com`)!
